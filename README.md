# Welsh Keys

Welsh Keys is a small Windows desktop utility for typing Welsh accented characters.

The prototype goal is simple:

- Keep a small keyboard window always on top
- Click a Welsh character
- Insert that character at the cursor in the previously active app
- Provide a copy-only fallback mode

## Prototype status

Version: 0.1 prototype

Current planned features:

- Core Welsh character buttons
- Shift toggle
- Insert-at-cursor mode
- Copy-only mode
- Dark keyboard-style interface
